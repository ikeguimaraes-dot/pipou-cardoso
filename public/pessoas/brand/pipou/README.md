# Pipou Academy — assets originais

Origem: `Arquivos/00. LAYOUT/PNG` e `Pipou-Branding-AGO26 (1).pdf`.

- `logo-yellow.png`: cópia sem alteração de `Pipou-02.png` (2244 × 890).
- `symbol-badge.png`: cópia sem alteração de `Pipou-05.png` (569 × 569).
- Amarelo digital: `#FCD616`, amostrado do PNG original.
- Carvão: `#231F20`, conforme apresentação do branding.
- Raleway Regular, Medium, SemiBold e Bold: arquivos locais originais fornecidos em `Fonts/Raleway`, usados em `src/app/fonts/pipou`.

Graphie e Connoire aparecem na apresentação, mas os arquivos completos dessas fontes não foram fornecidos. Não foram recriados nem substituídos dentro do logo; o logo continua sendo o original. Os componentes de interface usam Raleway fornecida.

A aplicação visual é centralizada em `src/app/pipou-theme.css`. Tons de superfície, hover e bordas são adaptações de interface, não especificações de componentes documentadas pelo guide. Cores semânticas de erro, sucesso e categorias foram preservadas.

O caminho público inclui `/pessoas` para funcionar no shell multi-zone existente. Não foram alteradas rotas, autenticação, permissões, APIs, banco, etapas de recrutamento ou modelos de documentos exportados.
